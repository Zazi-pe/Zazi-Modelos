Acceso

Para editar el catálogo, este dispositivo necesita un token de GitHub. Se guarda solo aquí.

  1. Abre github.com/settings/personal-access-tokens/new.
  2. Nombre: ZAZI admin. Elige una fecha de vencimiento.
  3. En Repository access, elige Only select repositories y marca Zazi-pe/Zazi y Zazi-pe/Zazi-Modelos.
  4. En Permissions, toca Add permissions y marca Contents. Luego, junto a Contents, cambia Read-only por Read and write.
  5. Toca Generate token, cópialo y pégalo aquí.
