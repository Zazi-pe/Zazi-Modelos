Acceso

Para editar el catálogo, este dispositivo necesita un token de GitHub. Se guarda solo aquí y sirve también para el admin de Zazi.

  1. Abre github.com/settings/personal-access-tokens. Si ya tienes el token de ZAZI admin, edítalo y agrega Zazi-pe/Zazi-Modelos; luego salta al paso 5.
  2. Si no, toca Generate new token. Nombre: ZAZI admin. Elige una fecha de vencimiento.
  3. En Repository access, elige Only select repositories y marca Zazi-pe/Zazi y Zazi-pe/Zazi-Modelos.
  4. En Permissions, toca Add permissions y marca Contents. Luego, junto a Contents, cambia Read-only por Read and write.
  5. Guarda, copia el token y pégalo aquí.
